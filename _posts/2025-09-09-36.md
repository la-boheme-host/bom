# 넷플릭스외교관

{% include auto-link.html url="https://www.netflix.com/title/81288983" %}

{% include video id="4rqCaAA7AlY" provider="youtube" %}

갑자기 영국 대사가 된 외교관 캐서린 와일러(케리 러셀 분)이 너무 유능해서 문제인 남편과 복잡한 외교 상황을 해결해내기 위해 고군분투하는 이야기입니다. 케리 러셀은 영화 어거스트 러쉬(2007)에서 어거스트의 엄마로 출연했던 배우입니다. 전체 8화로 역시 정주행하기 부담스럽지 않으며, 주인공의 문제 해결능력이 대단하지만, 그녀를 괴롭히는 문제는 끝없이 늘어만 갑니다. 결말은 시즌2가 나올것으로 암시하고 있습니다. 비슷한 외교 드라마로 마담 세크리터리가 있으며 쿠팡플레이에 시즌 6까지 올라와있습니다.

# 넷플릭스링컨차를 타는 변호사

{% include auto-link.html url="https://www.netflix.com/title/81303831" %}

{% include video id="tnD4vMU79yM" provider="youtube" %}

마이클 코넬리의 베스트셀러 소설 시리즈를 넷플릭스 드라마로 제작했습니다. 드라마 링컨 차를 타는 변호사는 속물 변호사이지만 실력은 좋은 미키 할러가 펼치는 선과 악, 정의와 불의, 양심과 죄의식 속의 드라마틱한 법정 스릴러입니다.  매튜 맥커너히가 주연을 맡은 동명의 영화 링컨 차를 타는 변호사(2011)도 꽤 재밌습니다. 의뢰인의 재판도 이기면서 의뢰인이 파놓은 함정도 피해야하는 두뇌 싸움이 흥미진진하게 펼쳐집니다.  

{% include auto-link.html url="https://m.kinolights.com/title/50065" %}

# 넷플릭스퀸스갬빗

{% include auto-link.html url="https://www.netflix.com/title/80234304" %}

{% include video id="2Kd_4OOfmE0" provider="youtube" %}

넷플릭스 시리즈 중에서 제가 가장 감명 깊게 본 시리즈입니다. 퀸스갬빗은 체스 오프닝 중의 하나로, 주인공 엘리자베스 하먼(안야 테일러조이 분)을 중심으로 고아원에서 자란 그녀가 체스 여왕이 되는 과정을 그려낸 작품입니다. 체스 대국을 사실적으로 잘 그려냈으며, 체스 대국을 하는 인물들의 심리까지도 잘 연출했습니다. 주인공 엘리자베스가 잠들기전 천장을 보며 상상으로 대국을 복기하는 장면이 가장 인상깊었습니다. 퀸스갬빗은 7편으로 정주행하기에도 부담스럽지 않습니다.
